# Iteration 07 - Definition Of Done

## Done Checklist

1. MVP scope is frozen.
2. Supported sources are explicit.
3. Known limitations are documented.
4. Onboarding works.
5. Support runbook exists.
6. Incident severity exists.
7. Launch checklist is complete.
8. Feedback taxonomy exists.
9. Beta metrics dashboard exists.
10. Full MVP loop works for beta user.
11. Rollback checklist exists.
12. Next-source decision process is evidence-based.

## Architecture Done

- Beta does not depend on unapproved source adapters.
- Source expansion still requires capability profile and risk class.
- Feedback links to tenant/topic/source/summary context.
- Launch does not bypass hardening gates.

## Evidence Required

- E2E beta smoke notes.
- Onboarding checklist.
- Support runbook.
- Known limitations doc.
- Feedback dashboard.
- Source expansion decision log.

## Not Done If

- Beta user cannot complete full loop.
- Support cannot diagnose failed scan.
- Unsupported source is treated as launch blocker.
- Feedback cannot be mapped to roadmap decisions.
