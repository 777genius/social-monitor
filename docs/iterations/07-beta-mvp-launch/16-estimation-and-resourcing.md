# Iteration 07 - Estimation And Resourcing

## Relative Effort

- Complexity: Medium
- Risk: High if scope is not frozen
- Recommended duration: 1 sprint plus beta observation window

## Required Roles

- Product owner
- Release owner
- Support owner
- SRE/on-call owner
- Backend/mobile owners for urgent fixes

## Parallel Work

1. Scope freeze and known limitations first.
2. Onboarding and support runbook can run together.
3. Metrics and feedback taxonomy can run before launch readiness review.

## Bottlenecks

- Unsupported source demand can derail beta.
- Poor onboarding can make summary quality look worse than it is.
- Support gaps delay learning loop.

## No-Cut Areas

- Scope freeze.
- Known limitations.
- Support runbook.
- Feedback taxonomy.
- Rollback checklist.
- Source expansion decision discipline.
