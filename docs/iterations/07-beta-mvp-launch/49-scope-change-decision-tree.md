# Iteration 07 - Scope Change Decision Tree

## Decision Goal
Prevent beta launch from turning into uncontrolled feature expansion.

## Accept Now If
- Change improves onboarding to the existing MVP loop.
- Change clarifies known limitations.
- Change improves rollback, support triage or feedback classification.

## Defer If
- Change requests new source coverage.
- Change requests enterprise features.
- Change requests broad reporting outside beta learning.

## Escalate To ADR If
- Change alters source expansion policy.
- Change changes launch go/no-go criteria.
- Change changes post-MVP architecture direction.

## Block If
- Change adds unsupported source during launch.
- Change removes rollback owner or pause path.
- Change converts anecdotal feedback into roadmap without evidence.

## Required Record
- Beta scope impact.
- User/support impact.
- Roadmap category.
- Evidence and owner.
