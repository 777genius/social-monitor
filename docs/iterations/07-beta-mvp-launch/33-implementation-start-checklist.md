# Iteration 07 - Implementation Start Checklist

## Prerequisites

1. Production hardening gates are green.
2. Scope is ready to freeze.
3. Support runbook exists.
4. Beta metrics are defined.

## Locked Before Work

1. Supported sources are explicit.
2. Known limitations are explicit.
3. Feedback taxonomy is mandatory.
4. Source expansion requires evidence and safe access.

## First Tickets

1. Freeze beta scope.
2. Prepare onboarding/support.
3. Run launch readiness review.
4. Start feedback loop.

## No-Go Items

- Adding new source during launch.
- Broad public launch.
- Feedback without roadmap mapping.
