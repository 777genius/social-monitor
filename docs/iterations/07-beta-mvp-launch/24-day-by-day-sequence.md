# Iteration 07 - Day By Day Sequence

## Day 1 - Scope Freeze

- Freeze supported sources.
- Freeze workflows.
- Document limitations.
- Check: no hidden beta-critical work remains.

## Day 2 - Onboarding

- Prepare onboarding.
- Seed demo topics/sources.
- Review vague-topic guidance.
- Check: user reaches useful summary.

## Day 3 - Launch Readiness

- Review launch checklist.
- Review rollback checklist.
- Review incident severity.
- Check: release owner can approve or block.

## Day 4 - Beta Run

- Launch limited beta.
- Monitor scan success, summary usefulness and quotas.
- Check: support can diagnose failures.

## Day 5 - Learning Loop

- Triage feedback.
- Classify source requests.
- Decide next priorities from evidence.
- Stop if feedback is not mapped to roadmap decisions.
