# Iteration 07 - Architecture Decision Record Seeds

## Purpose
List beta decisions that must be captured before post-MVP expansion.

## ADR Seeds
- Freeze supported beta source list.
- Define launch go/no-go and rollback triggers.
- Define feedback-to-roadmap classification.
- Define post-MVP source expansion criteria.
- Define known limitations policy.

## Alternatives To Capture
- Expand sources during beta vs freeze and learn.
- Roadmap by loudest request vs evidence/risk/cost classification.
- Hidden limitations vs explicit beta limitations.

## Consequences To Record
- Scope freeze protects reliability but may disappoint users.
- Evidence-based roadmap slows reaction but improves product decisions.
- Known limitations reduce surprise and support load.

## Revisit Triggers
- Source demand strongly exceeds expected volume.
- Users cannot complete core onboarding.
- Trust/relevance feedback contradicts metrics.
