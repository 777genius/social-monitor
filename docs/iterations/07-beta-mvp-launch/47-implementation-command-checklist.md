# Iteration 07 - Implementation Command Checklist

## Purpose
Record beta launch verification before launch or post-MVP promotion.

## Local Checks
- Walk through beta onboarding.
- Review known limitations.
- Run launch checklist.
- Review rollback/pause triggers.
- Classify feedback samples.
- Verify supported source list is frozen or change-controlled.

## Evidence To Attach
- Onboarding walkthrough result.
- Launch checklist status.
- Rollback owner list.
- Feedback taxonomy sample.
- Known limitations document link.

## MVP Evidence Rule
- Required: onboarding walkthrough, pause/rollback path, known limitations and feedback classification evidence.
- Defer: growth experiments, public-launch automation and enterprise onboarding until beta learning is clear.

## Blocking Failures
- Unsupported source enters launch scope.
- Launch cannot be paused safely.
- User cannot complete onboarding.
- Feedback has no owner, category or evidence.
