# Iteration 07 - Review Checklists

## Launch Review

1. MVP scope is frozen.
2. Supported sources are explicit.
3. Known limitations are documented.
4. Rollback checklist exists.
5. Launch checklist is complete.

## Support Review

1. Support can diagnose failed scans.
2. Support can diagnose failed summaries.
3. Provider quota failures are visible.
4. Feedback maps to tenant/topic/source/summary context.

## Product Review

1. Beta feedback taxonomy is in place.
2. Unsupported source requests are tracked.
3. Next-source decisions require evidence and source risk review.
4. Beta does not depend on unapproved adapters.
