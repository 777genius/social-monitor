# Iteration 07 - QA Acceptance Signoff

## Signoff Goal
Confirm that beta launch validates the core MVP loop with controlled scope and support readiness.

## Acceptance Scenarios
- Beta user completes onboarding.
- User creates topic, binds source, receives feed and summary.
- Known limitation is triaged by support.
- Rollback/pause checklist has owners.
- Feedback is classified into roadmap categories.

## Negative Cases
- Unsupported source request.
- Supported source outage.
- Launch pause with queued work.
- Feedback has no owner or evidence.

## Regression Coverage
- Onboarding walkthrough.
- Launch/rollback checklist.
- Feedback taxonomy examples.
- Known limitations examples.

## Residual Risks
- Broad source catalog remains post-MVP.
- Enterprise reporting remains post-MVP.

## Approvers
- Product owner.
- Engineering lead.
- Support owner.
- Operations owner.
