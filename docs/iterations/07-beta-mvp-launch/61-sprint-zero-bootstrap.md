# Iteration 07 - Sprint Zero Bootstrap

## Bootstrap Goal
Prepare beta launch work before onboarding, launch or roadmap decisions begin.

## Setup Tasks
- Assign product, engineering, support, operations and source policy owners.
- Confirm beta scope freeze.
- Confirm supported source list.
- Confirm launch/rollback decision owners.
- Confirm feedback taxonomy.

## First Artifacts
- Beta scope document.
- Known limitations draft.
- Onboarding walkthrough.
- Launch and rollback checklist.
- Feedback classification template.

## Preflight Checks
- Supported sources are frozen or change-controlled.
- Launch can be paused.
- Support triage path is known.
- Feedback categories include demand, risk, trust, UX, reliability and cost.

## Start Blockers
- Rollback owner missing.
- Known limitations missing.
- Unsupported source requests entering scope.
- Onboarding cannot reach first summary.
