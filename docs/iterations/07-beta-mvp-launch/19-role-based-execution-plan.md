# Iteration 07 - Role-Based Execution Plan

## Product Owner

- Freeze beta scope.
- Own known limitations.
- Own feedback taxonomy.
- Prioritize next-source roadmap.

## Release Owner

- Own launch checklist.
- Own rollback plan.
- Coordinate readiness review.

## Support Owner

- Own onboarding.
- Own support runbook.
- Triage beta issues.

## SRE/On-Call

- Monitor beta health.
- Watch quotas, provider failures and cost.
- Escalate incidents.

## Backend/Mobile Owners

- Handle urgent launch defects.
- Keep contracts stable.
- Avoid scope expansion during beta.

## Handoffs

- Beta feedback -> roadmap.
- Source requests -> source research/adapters.
- Operational incidents -> hardening backlog.
