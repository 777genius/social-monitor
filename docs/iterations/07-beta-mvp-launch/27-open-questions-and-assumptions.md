# Iteration 07 - Open Questions And Assumptions

## Working Assumptions

1. Beta validates the core loop, not every future source.
2. Supported sources are frozen before launch.
3. Feedback is structured and tied to roadmap decisions.
4. Unsupported source requests are tracked but not auto-accepted.

## Open Questions

| Question | Owner | Deadline | Decision Impact |
| --- | --- | --- | --- |
| How many beta users/workspaces are allowed first? | Product/ops | Before launch | Quotas/support |
| What is the minimum success metric for summary usefulness? | Product/AI | Before feedback review | Roadmap |
| Which source request threshold triggers research? | Product/source owner | Before beta | Source roadmap |
| What is the rollback trigger during beta? | Release/SRE | Before launch | Incident plan |

## Validation Rule

Do not expand source scope until beta evidence and production-safe acquisition path both exist.
