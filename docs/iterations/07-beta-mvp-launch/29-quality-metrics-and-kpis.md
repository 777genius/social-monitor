# Iteration 07 - Quality Metrics And KPIs

## Primary Quality Signals

| Metric | Target |
| --- | --- |
| Beta user full-loop completion | Measured per cohort |
| Scan success rate | Tracked by source |
| Summary usefulness feedback | Tracked by topic |
| Unsupported source requests | Categorized |
| Support issues with diagnosis path | 100% for known failure classes |

## Failure Signals

- Feedback cannot be mapped to roadmap decisions.
- Unsupported source demand overrides source safety policy.
- Known limitations are unclear to users.

## Review KPI

Beta is healthy when it produces evidence for next product/source priorities without destabilizing the MVP loop.
