# Iteration 07 - PR Review Rubric

## Review Goal
Ensure beta-launch PRs protect scope, supportability and evidence-based roadmap decisions.

## Architecture Checks
- Source policy remains enforced.
- Beta scope is frozen or explicitly change-controlled.
- Post-MVP items preserve ports/adapters and bounded contexts.
- Feedback does not create architecture shortcuts.

## Test And Evidence Checks
- Onboarding walkthrough is attached.
- Launch/rollback checklist is reviewed.
- Known limitations are updated.
- Feedback samples are classified.

## Edge Case Checks
- Unsupported source request.
- Supported source outage.
- Launch pause with queued work.
- Metrics and trust feedback conflict.

## Merge Blockers
- Unsupported source enters launch scope.
- Rollback owner missing.
- User cannot complete onboarding.
- Feedback lacks evidence or owner.
