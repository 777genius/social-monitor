# Iteration 07 - Phase To Ticket Map

| Phase | Ticket Groups | Key Artifacts | Closure Evidence |
| --- | --- | --- | --- |
| 01-beta-scope-freeze | Scope, sources, limitations | Scope freeze | No hidden beta scope |
| 02-onboarding-support | Onboarding, support docs, demo topics | Onboarding/runbook | User reaches summary |
| 03-launch-readiness | Checklist, rollback, incidents | Launch pack | Release approved |
| 04-post-beta-learning-loop | Metrics, feedback, source requests | Learning loop | Next priorities evidence-based |

## Ticket Cutting Rule

Each beta ticket must state user impact, support impact and whether it changes launch scope.

## Traceability Rule

Before a ticket is ready, map it to `08-ticket-breakdown.md`, `11-acceptance-test-plan.md`, `14-traceability-matrix.md` and `59-traceable-evidence-register.md`. If the ticket cannot produce evidence, split or rewrite it.
