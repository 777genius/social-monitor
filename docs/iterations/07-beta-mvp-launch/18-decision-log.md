# Iteration 07 - Decision Log

## Decision 001 - Beta Scope Freeze Before Launch

- Decision: Freeze supported sources and workflows before beta.
- Alternatives: Continue adding sources during launch.
- Rationale: Beta should validate the core loop, not chase scope.
- Consequences: Some requested sources move to roadmap.
- Revisit When: Beta evidence shows a source is essential and safe to add.

## Decision 002 - Next Source Decisions Are Evidence-Based

- Decision: Prioritize new sources from beta demand, reliability and production-safe access.
- Alternatives: Add sources by intuition.
- Rationale: Source expansion is expensive and affects reliability.
- Consequences: Requires feedback taxonomy and source request tracking.
- Revisit When: Strategic customer commitment changes priorities.
