# Iteration 07 - Sprint Review Demo Script

## Review Goal
Prove that beta launch is controlled, supportable and tied to measurable learning.

## Demo Flow
1. Walk through beta scope freeze.
2. Onboard a beta user through the core loop.
3. Show known limitations and support triage path.
4. Run launch checklist and rollback trigger review.
5. Show feedback taxonomy and success metrics dashboard.

## Evidence To Show
- Supported sources are frozen.
- Onboarding path covers first topic, source binding, scan and summary.
- Known limitations are explicit.
- Rollback/pause owners and triggers are named.
- Feedback maps to roadmap decision categories.

## Edge Cases To Exercise
- Beta user requests unsupported source.
- Supported source fails during launch week.
- Summary quality feedback conflicts with metrics.
- Launch must pause without data loss.

## Review Questions
- Is beta validating the core loop rather than adding scope?
- Can support triage issues without engineering guessing?
- Are roadmap decisions evidence-based?

## Accept Progress If
- Launch can proceed or pause with clear owner.
- Feedback loop is ready.
- Known limitations are visible before beta users hit them.
