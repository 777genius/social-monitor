# Iteration 07 - Backlog Prioritization Matrix

## Prioritization Goal
Validate the MVP loop and beta learning before post-MVP expansion.

## P0 - Do First
- Beta scope freeze.
- Supported source list.
- Onboarding walkthrough.
- Launch and rollback checklist.
- Known limitations.

## P1 - Do After P0
- Feedback taxonomy.
- Metrics dashboard.
- Support triage flow.
- Post-beta roadmap classification.
- ADR and quality-gate updates.

## P2 - Defer If Needed
- New source implementation.
- Enterprise features.
- Broad reporting.
- Advanced admin controls.

## Prioritize Higher When
- Work affects user onboarding.
- Work affects rollback safety.
- Work affects source-policy compliance.
- Work affects evidence-based roadmap decisions.

## Do Not Prioritize
- Source expansion during launch.
- Roadmap promises before feedback classification.
- Feature additions before core loop validation.
