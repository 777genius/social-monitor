# Iteration 00 - Risk Burndown And Control Points

## Burndown Goal
Reduce ambiguity risk before any platform code starts.

## Day 1 Control Point
- Product loop is agreed.
- Glossary draft has no conflicting core terms.
- Source policy owner is assigned.

## Midpoint Control Point
- Bounded contexts have owners.
- Source policy has allowed, restricted and blocked examples.
- Contract/event standards include tenant scope and idempotency.

## Closeout Control Point
- No critical foundation assumption is ownerless.
- Iteration 01 tickets can reference accepted vocabulary and contract rules.
- Source decisions cannot bypass policy.

## Escalation Threshold
Escalate if any team cannot explain how its first implementation tickets map to the product loop and bounded contexts.

## Residual Risk Rule
Residual foundation risk can carry forward only with owner, decision deadline and no effect on platform scaffold start.
