# Iteration 00 - Production Readiness Gap Analysis

## Readiness Goal
Ensure planning foundations are strong enough for a production-shaped MVP, even before implementation exists.

## MVP-Ready Areas
- Product loop is explicit.
- Core vocabulary is shared.
- Bounded contexts are defined.
- Source acquisition policy is documented.
- Contract standards are planned.

## Acceptable MVP Gaps
- Some source-specific operational limits can remain estimated.
- Exact post-MVP source roadmap can remain unranked.
- Some contract examples can be refined during Iteration 01 if rules are clear.

## Blocking Gaps
- No source policy owner.
- No tenant-safe model assumptions.
- No contract versioning rule.
- No bounded-context ownership.

## Owner Actions
- Product owner resolves vocabulary gaps.
- Architecture owner resolves context gaps.
- Source policy owner resolves source-risk gaps.
- Contract owner resolves API/event gaps.

## Follow-Up
Carry unresolved implementation-specific decisions into Iteration 01 only if they have owner, deadline and non-blocking classification.
