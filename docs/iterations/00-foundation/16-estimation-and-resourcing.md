# Iteration 00 - Estimation And Resourcing

## Relative Effort

- Complexity: Medium
- Risk: High if rushed
- Recommended duration: 3-5 focused days

## Required Roles

- Product owner
- Backend architect
- Mobile architect
- Source/ingestion owner
- SRE/security reviewer

## Parallel Work

1. Product loop and glossary can run with context mapping.
2. Source acquisition policy can run with contract standards.
3. Flutter architecture rules can run after bounded contexts are named.

## Bottlenecks

- Unclear source policy blocks ingestion.
- Unclear bounded contexts block monorepo structure.
- Unclear REST/event standards block API and workers.

## No-Cut Areas

- Source acquisition policy.
- Bounded context ownership.
- Contract versioning.
- Architecture guardrails.
