# Iteration 00 - Day By Day Sequence

## Day 1 - Product Loop And Vocabulary

- Define MVP loop.
- Define glossary.
- Mark non-goals.
- Check: every term maps to user-visible or system responsibility.

## Day 2 - Contexts And Ownership

- Define bounded contexts.
- Assign aggregate ownership.
- Identify cross-context events/APIs.
- Check: no aggregate has two write owners.

## Day 3 - Architecture And Source Policy

- Write Clean Architecture guardrails.
- Write source acquisition policy.
- Write source risk classes.
- Check: unsafe production scraping is rejected.

## Day 4 - Contract Standards

- Define REST/OpenAPI rules.
- Define event envelope/versioning.
- Define gRPC usage.
- Check: future tickets can state contract impact.

## Day 5 - Closure Review

- Review ticket quality rule.
- Review traceability.
- Review DoD.
- Stop if context ownership, source policy or contract standards are unclear.
