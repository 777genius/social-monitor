# Iteration 00 - Sprint Zero Bootstrap

## Bootstrap Goal
Prepare the foundation iteration so product, architecture and source-policy work starts with named owners and clear artifacts.

## Setup Tasks
- Assign product, architecture, source policy and contract owners.
- Open the product loop draft and glossary file.
- Open the context map workspace.
- Open source policy and contract standards templates.

## First Artifacts
- Product loop outline.
- Glossary seed.
- Bounded context sketch.
- Source policy matrix.
- REST/event contract examples.

## Preflight Checks
- Every owner knows the decision they own.
- Core loop has start and end states.
- Source policy includes at least one allowed, restricted and blocked example.
- Contract examples include tenant scope and version field.

## Start Blockers
- No source policy owner.
- No architecture owner.
- Product loop is not agreed at high level.
- Team cannot explain why multi-tenancy is modeled from day one.
