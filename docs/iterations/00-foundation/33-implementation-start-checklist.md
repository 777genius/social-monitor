# Iteration 00 - Implementation Start Checklist

## Prerequisites

1. Product goal is understood.
2. MVP loop is accepted as the core delivery loop.
3. Future multi-tenancy is a real architecture requirement.
4. Source ingestion must use production-safe adapters.

## Locked Before Work

1. No implementation code in this iteration.
2. No source is approved without risk class.
3. No context is accepted without ownership.
4. No ticket is accepted without tests and edge cases.

## First Tickets

1. Define MVP loop and glossary.
2. Define bounded context map.
3. Define source acquisition policy.
4. Define contract standards.

## No-Go Items

- Building scraper-first prototype.
- Starting NestJS code before context map.
- Adding source scope without production-safe path.
