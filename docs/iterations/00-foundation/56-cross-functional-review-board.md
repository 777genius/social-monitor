# Iteration 00 - Cross-Functional Review Board

## Review Goal
Approve foundation decisions from product, architecture, backend, mobile, source policy and operations perspectives.

## Required Reviewers
- Product owner.
- Architecture owner.
- Backend lead.
- Mobile lead.
- Source policy owner.
- Operations/support representative.

## Review Questions
- Does the product loop describe real user value?
- Are bounded contexts clear enough for implementation?
- Does source policy block unsafe acquisition paths?
- Can backend and mobile share the same contract language?
- Are support-visible limitations already explicit?

## Required Evidence
- Glossary.
- Context map.
- Source policy.
- Contract standards.
- Ticket quality rule.

## Approval Rule
Promote only if every reviewer can create or review tickets without inventing missing assumptions.
