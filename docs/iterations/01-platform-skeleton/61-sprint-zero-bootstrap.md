# Iteration 01 - Sprint Zero Bootstrap

## Bootstrap Goal
Prepare platform implementation before code scaffolding begins.

## Setup Tasks
- Assign backend, platform, contract and QA owners.
- Confirm monorepo package manager and tooling.
- Confirm local database and broker services.
- Confirm migration and OpenAPI generation approach.

## First Artifacts
- Monorepo folder skeleton plan.
- Local infra compose/service list.
- Migration workflow note.
- Outbox/idempotency design sketch.
- Initial OpenAPI endpoint list.

## Preflight Checks
- Import-boundary rule is defined.
- Domain/application/adapter folders are named.
- Tenant context strategy is known.
- Duplicate command behavior is specified.

## Start Blockers
- ORM/migration choice unresolved.
- Contract generation path unclear.
- Outbox/idempotency owner missing.
- Domain boundary rules not accepted.
