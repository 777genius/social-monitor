# Iteration 01 - Implementation Start Checklist

## Prerequisites

1. Foundation documents are accepted.
2. Context map is available.
3. Contract standards are available.
4. Source policy is available.

## Locked Before Work

1. Monorepo starts modular before physical service split.
2. Outbox and idempotency are part of MVP skeleton.
3. OpenAPI generation is mandatory.
4. Tenant context is mandatory.

## First Tickets

1. Scaffold NestJS monorepo.
2. Add local infrastructure.
3. Add core migrations.
4. Add baseline REST/OpenAPI.

## No-Go Items

- Deferring architecture tests.
- Deferring idempotency.
- Manual OpenAPI maintenance.
