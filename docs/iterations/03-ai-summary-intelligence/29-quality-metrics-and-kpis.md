# Iteration 03 - Quality Metrics And KPIs

## Primary Quality Signals

| Metric | Target |
| --- | --- |
| User-visible summaries with citations | 100% |
| Structured output validation coverage | 100% |
| Summary jobs with token/cost telemetry | 100% |
| Prompt/model changes with eval run | 100% |
| Feedback records linked to topic/summary | 100% |

## Failure Signals

- Summary claim lacks evidence.
- AI provider output is persisted without validation.
- Cost is not visible by tenant/topic/job.

## Review KPI

Summarization is healthy when outputs are cited, auditable, evaluated and cost-tracked.
