# Iteration 03 - Sprint Zero Bootstrap

## Bootstrap Goal
Prepare summary intelligence work before AI provider or prompt implementation begins.

## Setup Tasks
- Assign AI, evidence, backend, eval and cost owners.
- Confirm SummaryPolicy fields.
- Confirm citation strictness.
- Confirm provider-port boundary.
- Confirm eval and telemetry requirements.

## First Artifacts
- SummaryPolicy draft.
- Evidence/citation schema draft.
- AiSummarizerPort request/response sketch.
- Structured output schema.
- Golden eval seed set.

## Preflight Checks
- Final summary trust rule is explicit.
- Provider output validation path is known.
- Cost attribution dimensions are known.
- Mobile citation display needs are reviewed.

## Start Blockers
- Citation strictness unresolved.
- Provider-specific schema planned for public API.
- Eval owner missing.
- Cost telemetry not defined.
