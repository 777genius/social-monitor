# Iteration 03 - Execution Calendar And Cadence

## Cadence Goal
Validate summary trust, citations, evals and cost controls before mobile exposure.

## Kickoff
- Confirm SummaryPolicy, citation strictness, provider port and eval owner.
- Review evidence model and mobile display needs.
- Confirm cost attribution dimensions.

## Midpoint
- Run structured output validation tests.
- Run citation negative cases.
- Run initial eval harness.
- Review cost telemetry sample.

## Review
- Demonstrate cited summary generation.
- Demonstrate invalid output rejection.
- Review eval and telemetry evidence.

## Closeout
- Complete summary go/no-go.
- Hand off summary, citation and failure contracts to mobile.
- Record quality risks and eval follow-ups.

## Stop Conditions
- Final summary can be uncited.
- Provider schema leaks into public API.
- Cost cannot be attributed.
