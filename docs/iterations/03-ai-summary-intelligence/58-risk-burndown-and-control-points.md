# Iteration 03 - Risk Burndown And Control Points

## Burndown Goal
Reduce summary trust, validation and cost risk before mobile exposes generated output.

## Day 1 Control Point
- SummaryPolicy fields are agreed.
- Citation strictness is decided.
- Provider port boundary is drafted.

## Midpoint Control Point
- Structured output validation rejects malformed output.
- Citation validation catches missing references.
- Eval harness has first golden cases.

## Closeout Control Point
- Final summaries cannot be uncited.
- Cost telemetry is attributable.
- Mobile can consume stable summary and citation contracts.

## Escalation Threshold
Escalate if useful summary output cannot satisfy citation or validation rules.

## Residual Risk Rule
Eval dataset size may carry forward; citation, validation and cost attribution risks may not.
