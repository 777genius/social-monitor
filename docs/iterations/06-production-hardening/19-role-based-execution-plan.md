# Iteration 06 - Role-Based Execution Plan

## Security Engineer

- Own tenant isolation tests.
- Own credential encryption.
- Own secret redaction checks.

## SRE/DevOps

- Own dashboards.
- Own alerts.
- Own backup/restore.
- Own CI/CD hardening.

## Backend Platform

- Add correlation/causation IDs.
- Add quota enforcement.
- Add retry-budget controls.

## QA/Load Testing

- Run queue backlog simulations.
- Run provider outage scenario.
- Run cost spike scenario.

## Support Owner

- Validate runbooks.
- Validate dashboard usefulness.
- Prepare incident workflow.

## Handoffs

- Dashboards -> support.
- Alerts -> on-call.
- Quotas -> product/support.
- Rollback plan -> release owner.
