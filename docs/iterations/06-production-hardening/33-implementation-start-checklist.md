# Iteration 06 - Implementation Start Checklist

## Prerequisites

1. Core loop works.
2. Realtime status is reliable.
3. Provider failure taxonomy exists.
4. Support needs are known.

## Locked Before Work

1. Tenant isolation is launch gate.
2. Secret redaction is launch gate.
3. Dashboards/runbooks are MVP work.
4. CI contract/migration gates are mandatory.

## First Tickets

1. Add tenant isolation tests.
2. Add secret redaction.
3. Add core dashboards.
4. Add CI gates.

## No-Go Items

- Beta before tenant isolation.
- Support relying on developer shell.
- Cost without quota/visibility.
