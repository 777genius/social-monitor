# Iteration 06 - Backlog Prioritization Matrix

## Prioritization Goal
Close beta blockers before enterprise-grade enhancements.

## P0 - Do First
- Tenant isolation tests.
- Secret encryption and redaction.
- CI contract/event/migration gates.
- Support-visible dashboards.
- Quotas and cost controls.

## P1 - Do After P0
- Backup/restore verification.
- Runbooks.
- Alert tuning.
- Rollback evidence.
- Known limitation support notes.

## P2 - Defer If Needed
- Enterprise compliance certifications.
- Advanced autoscaling.
- Incident automation.
- Long-term capacity planning.

## Prioritize Higher When
- Work affects tenant safety.
- Work affects secret leakage.
- Work affects beta launch gate.
- Work affects support diagnosis.

## Do Not Prioritize
- Enterprise polish before beta safety.
- Dashboards without user-visible failure signals.
- Quota UI before quota enforcement.
