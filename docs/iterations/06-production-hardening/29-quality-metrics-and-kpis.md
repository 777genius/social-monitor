# Iteration 06 - Quality Metrics And KPIs

## Primary Quality Signals

| Metric | Target |
| --- | --- |
| Cross-tenant negative tests pass | 100% |
| Secret redaction tests pass | 100% |
| Core health dashboards available | 100% |
| CI contract/migration/schema gates active | 100% |
| Support runbooks for common failures | 100% |

## Failure Signals

- Support needs shell access for normal diagnosis.
- Provider outage creates unbounded retries.
- Cost spike is not visible.

## Review KPI

Hardening is healthy when the platform is diagnosable, bounded and safe for beta users.
