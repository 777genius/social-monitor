# Iteration 04 - Execution Calendar And Cadence

## Cadence Goal
Complete the Flutter core loop before realtime is layered onto it.

## Kickoff
- Confirm feature-slice structure, generated client workflow and store responsibilities.
- Review UI state matrix.
- Confirm required headless component usage.

## Midpoint
- Review topic and source-binding flows.
- Run mapper and store tests.
- Review API contract mismatches.

## Review
- Demonstrate topic -> source -> feed -> summary -> citation loop.
- Demonstrate loading, empty, error, stale and offline states.
- Review DTO/domain boundary evidence.

## Closeout
- Complete mobile go/no-go.
- Hand off store and UI-state contracts to realtime work.
- Record polish and offline carryover.

## Stop Conditions
- DTOs are used as domain models.
- Core loop is incomplete.
- Failure states are hidden.
