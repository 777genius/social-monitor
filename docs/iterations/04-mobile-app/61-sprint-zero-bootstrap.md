# Iteration 04 - Sprint Zero Bootstrap

## Bootstrap Goal
Prepare Flutter implementation before feature slices are created.

## Setup Tasks
- Assign Flutter, API, product, design/system and QA owners.
- Confirm generated client workflow.
- Confirm feature folder convention.
- Confirm MobX store responsibilities.
- Confirm required headless component usage.

## First Artifacts
- App shell plan.
- Generated client adapter plan.
- Feature slice template.
- DTO-to-domain mapper example.
- UI state matrix.

## Preflight Checks
- DTOs are restricted to infrastructure.
- Core loop screens are identified.
- Loading, empty, error, stale and offline states are listed.
- Citation drill-down expectation is known.

## Start Blockers
- OpenAPI unavailable or unstable.
- Feature architecture convention unresolved.
- Store ownership unclear.
- Required component usage unclear.
