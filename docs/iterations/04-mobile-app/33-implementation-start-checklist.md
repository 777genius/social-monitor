# Iteration 04 - Implementation Start Checklist

## Prerequisites

1. OpenAPI generation works.
2. Topic/source/feed/summary APIs are scoped.
3. Required headless component strategy is accepted.
4. Mobile platform target is chosen or explicitly deferred.

## Locked Before Work

1. Feature-scoped Clean Architecture is mandatory.
2. Generated DTOs stay in infrastructure.
3. MobX stores are presentation orchestration only.
4. Failure states are part of MVP.

## First Tickets

1. Build Flutter app shell.
2. Add generated client adapter boundary.
3. Build topic/source flow.
4. Build feed/summary flow.

## No-Go Items

- Marketing page instead of actual app.
- UI polish before full MVP loop.
- Screens without error/stale states.
