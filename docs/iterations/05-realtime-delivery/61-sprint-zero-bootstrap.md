# Iteration 05 - Sprint Zero Bootstrap

## Bootstrap Goal
Prepare realtime implementation before gateway and mobile live updates begin.

## Setup Tasks
- Assign realtime, auth, mobile, backend and operations owners.
- Confirm event DTO list.
- Confirm channel authorization model.
- Confirm reconnect/resync contract.
- Confirm notification idempotency model.

## First Artifacts
- Realtime event schema draft.
- Channel naming and auth matrix.
- Resync snapshot example.
- Notification read-model sketch.
- Delivery metric list.

## Preflight Checks
- REST auth rules are available.
- Events have tenant scope and version.
- Mobile store integration path is known.
- Duplicate event behavior is defined.

## Start Blockers
- Channel authorization unresolved.
- Resync path missing.
- Notification idempotency unclear.
- Realtime planned as source of truth.
