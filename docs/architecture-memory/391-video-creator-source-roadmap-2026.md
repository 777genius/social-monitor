# 391 - Video/Creator Source Roadmap 2026

## Last Verified

2026-06-04.

## Purpose

This roadmap sequences video, live and creator platforms after the core MVP.

## MVP Core

Prioritize:

- YouTube basic search/channel/comment monitoring
- RSS/open web
- Reddit
- Hacker News

Reason:

- highest demand
- clearer APIs
- broad user value

## Early SaaS

Add:

- Vimeo owned/library monitoring
- Steam app reviews for gaming users
- Product Hunt launch monitoring
- Patreon public/owned creator updates if creator vertical matters

Reason:

- good vertical value
- manageable source contracts

## Experimental / Optional

Add:

- Dailymotion
- PeerTube
- Odysee
- Rumble vendor/partner
- Kick official API after validation
- Indiegogo campaigns/updates
- Kickstarter public watchlists

Reason:

- useful but narrower or less reliable

## Enterprise / Vertical Packages

Add:

- creator monetization owned accounts
- crowdfunding campaign dashboards
- live-stream analytics vendors
- regional video platforms such as Bilibili/Douyin/Kuaishou via vendor/partner access

## Architecture Rule

Do not mix video, creator payments, campaign updates and social comments into one generic feed model without typed source capabilities.
