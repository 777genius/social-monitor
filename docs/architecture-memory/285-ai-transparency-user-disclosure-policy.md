# 285 - AI Transparency User Disclosure Policy

## Decision

Users must be able to understand when summaries are AI-generated, what source window they came from and what evidence supports them.

AI transparency is product UI, audit metadata and governance evidence.

## Sources

- EU AI Act overview, European Commission: https://digital-strategy.ec.europa.eu/en/policies/regulatory-framework-ai
- EU General-purpose AI obligations: https://digital-strategy.ec.europa.eu/en/factpages/general-purpose-ai-obligations-under-ai-act
- NIST AI RMF Generative AI Profile: https://www.nist.gov/publications/artificial-intelligence-risk-management-framework-generative-artificial-intelligence
- ISO/IEC 42001: https://www.iso.org/standard/42001

## User-Facing Disclosure

Summary UI should show:

- generated by AI
- source types included
- time window
- number of items considered
- generation time
- confidence/uncertainty where available
- citations/source links
- human review status where applicable

Do not present AI summary as verified fact without evidence.

## Metadata

Persist:

```text
summary_id
ai_generated = true
model_id
prompt_version
schema_version
source_window
source_item_ids
human_review_state
confidence_signals
generated_at
```

## Limited-Risk Transparency

Where AI transparency obligations apply, disclose AI interaction/generation clearly and early enough for the user to understand the nature of the content.

The product does not initially generate deepfakes or synthetic media, but text summaries still need clear labeling.

## Tenant Configuration

Tenants may configure:

- summary style
- risk labels
- review requirements
- disclosure wording
- whether digest emails include AI label

They may not disable required legal/product transparency.

## External Sharing

Exported summaries/digests should include:

- AI-generated label
- generation timestamp
- source window
- citation references
- disclaimer that summary is derived from monitored sources

## Governance Evidence

Keep evidence for:

- model/provider used
- evaluation gate passed
- prompt/schema version
- data minimization policy
- review decision where applicable

## Architecture Rule

Transparency is not a tooltip.

It must be present in data model, API, UI and exports.
