# Реальные посты: reference dataset r2

50 вручную выбранных пар, 49 публичных постов, 12 тематических контекстов из frozen capture 30 августа — 5 сентября 2026 UTC. Провайдеры исходного корпуса: X/Twitter, Reddit, Hacker News; RSS/GitHub в этих 3480 входных постах нет. Нового сбора публикаций не было.

46 scored, 4 ambiguous. 23 семантических same_story, из них 15 cross-provider; 8 same-provider controls сохраняют отдельные product posts по текущему контракту. Пять из 15 cross-provider positives относятся к одному запуску Fable/Mythos: они проверяют неоднозначную многопостовую группировку, а не пять независимых событий. Выборка не случайная; population accuracy, доверительные интервалы для популяции и общий accuracy здесь неуместны.

Аналитик сначала просматривал blind corpus: инвентарь заголовков, поиск по названиям/URL и лексическое ранжирование для поиска материалов. Затем лично прочитал полный доступный sourceText всех выбранных публикаций. Лексический поиск использовался только для навигации, не для меток или предсказаний. Метки записаны по событиям, участникам, версиям, времени и основному утверждению. Семантическая близость не удостоверяет истинность рассказов об атаках, моделях или результатах измерений. Независимой второй разметки нет.

- `posts.jsonl`: публичные нормализованные тексты целиком для выбранных небольших постов, канонические URL, авторы, UTC publishedAt/observedAt, исходные evidence hash и hash sourceText.
- `cases.json`: устойчивые ID, объяснения по-русски, semanticRelation и отдельно productAction. `related_topic` здесь аналитическая связь; это не обещание допуска в production related-topic metadata.
- `blocks.json`: точный состав и порядок контекстов. Десять контекстов содержат 3+ поста. Оценены только явно размеченные рёбра; неразмеченные рёбра не превращаются в gold автоматически. Отчёт показывает полный состав кластеров и перестановку входного порядка.
- `label-seal.json`: SHA256 трёх файлов выше, revision, capture identity, hashes исходных blind/replay файлов и фактическое время замораживания. Сформирован до первого запуска production-функций на данных. После просмотра результатов метки не исправлялись.
- `replay.jsonl`: отдельная проекция исходного normalized replay, извлечённая после фиксации меток. Исходные score/contentQuality/promotionFacts сохранены как входные факты системы, не как semantic gold. Source/binding/interest IDs заменены явно фиктивными. Provider payloads, credentials и реальные tenant/workspace IDs не копировались.
- `replay-seal.json`: связывает проекцию с замороженными метками.

Границы: RSG-036 содержит только внешнюю ссылку в Reddit; RSG-040/041 используют title-only HN; RSG-020 имеет спорную гранулярность postmortem/research. Все четыре видны, но не scored. Музыкант GEMINI и Google Gemini дают отрицательный контроль омонимии. Установленные названия моделей и даты сохранены как наблюдённые данные, без проверки утверждений вне frozen corpus.

Запуск и точная цепочка production-функций: `scripts/evals/reader-story-grouping/README.md`. Результаты и HTML находятся в игнорируемом `.cache/real-story-grouping-eval/`.
