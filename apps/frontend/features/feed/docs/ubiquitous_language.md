# Feed Ubiquitous Language

## Purpose

Owns mention review, feed filters, triage and feed item workflow language.

## Core Terms

- Feed item: normalized mention or observation ready for review.
- Triage state: current review decision for a feed item.
- Feed filter: user-visible criteria for narrowing the review list.

## Forbidden Synonyms

- Do not call provider payloads feed items until they pass anti-corruption mapping.
