# Settings Ubiquitous Language

## Purpose

Owns workspace governance, account preferences, diagnostics and settings workflow language.

## Core Terms

- Preference: user or workspace setting that changes product behavior.
- Diagnostic: read-only operational state exposed to a user.
- Governance setting: workspace-level control with policy impact.

## Forbidden Synonyms

- Do not mix account preference names with workspace governance names.

## Open Questions

- Which settings are workspace-owned and which are user-owned?
