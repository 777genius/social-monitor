# Topics Ubiquitous Language

## Purpose

Owns monitoring intent, topic rules, keywords, markets, languages and topic lifecycle language.

## Core Terms

- Topic: monitored intent configured by a workspace.
- Keyword: user-defined term that helps identify relevant activity.
- Market: geographic or business scope for monitoring.
- Topic lifecycle: creation, update, archive and reactivation state.

## Forbidden Synonyms

- Do not call every search query a topic unless it is a configured monitoring intent.
