# Summaries Ubiquitous Language

## Purpose

Owns briefings, digests, summary review and insight workflow language.

## Core Terms

- Summary: generated explanation of monitored activity.
- Digest: scheduled collection of summaries for a workspace or user.
- Briefing: product-facing summary view optimized for quick review.
- Insight: notable claim or pattern derived from monitored items.

## Forbidden Synonyms

- Do not expose model provider terms as summary domain language.
